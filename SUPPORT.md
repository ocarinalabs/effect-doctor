# Support

Use GitHub issues for reproducible installation, CLI, report, and rule problems once the repository is public. Search existing issues first and use the matching issue form.

Include the Effect Doctor version, Node version, operating system, command, exit code, and a minimal project or redacted JSON report. Do not attach proprietary source unless a maintainer has provided a private channel.

Rule disagreements belong in a rule-proposal issue with an Effect source or documentation reference and close-valid counterexamples. Security reports follow [SECURITY.md](SECURITY.md), never the public issue tracker.

While the repository is private, use [Ocarina Labs' get-in-touch page](https://www.ocarinalabs.ai/) for access or support questions.
