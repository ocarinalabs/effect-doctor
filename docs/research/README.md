# Research index

This directory records dated evidence used to admit, delegate, reject, or defer Effect Doctor rules. Documents may describe an earlier catalog snapshot; their pinned commits and package versions define their scope.

Use these sources in this order:

1. `effect-doctor rules list` and `rules explain` for current behavior.
2. `src/generated/rule-catalog.ts` for the checked-in generated contract.
3. `first-party-rules.md` for first-party provenance and abstentions.
4. The ecosystem and evaluation reports for historical evidence and calibration.

An audit remains useful after the catalog changes because it explains a decision at a pinned upstream revision. It must not be cited as the current rule count or default policy unless its snapshot still matches the generated catalog.
